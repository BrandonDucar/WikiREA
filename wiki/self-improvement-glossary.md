# Self-Improvement Glossary

These terms connect the [DSPy](dspy-optimization.md),
[DGM](darwin-godel-machine.md) and [AlphaEvolve client](alphaevolve-client.md)
investigations. Definitions are original synthesis, not reproduced test results.

| Term | Meaning And Important Boundary |
| --- | --- |
| Optimizer | Selects or revises candidates against an objective; not necessarily the component being revised. |
| Compiled program | An artifact produced by an optimization/compilation process; not proof of general intelligence or deployment readiness. |
| Demonstration | Example supplied to a predictor; a successful example is not an untouched test. |
| Metric | Scoring function; its validity, version and failure handling need independent review. |
| Training set | Examples available for fitting, reflection or candidate construction. |
| Validation set | Examples used during selection; repeated exposure can influence the selected candidate. |
| Final holdout | Unseen evaluation withheld from candidate search; must remain separate in access and lineage. |
| Baseline | Versioned reference artifact and evaluation conditions used for comparison. |
| Candidate | Proposed prompt, program or agent revision; no automatic execution authority. |
| Lineage | Parent and descendant identities plus transformations and evaluation versions. |
| Archive | Retained search history; can intentionally include inferior or failed candidates. |
| Promotion | Separate decision to admit a candidate for a declared use and scope. |
| Pareto frontier | Candidates not dominated across declared objectives; does not itself establish safety or generalization. |
| Evaluator | Component that tests a candidate; reported scores still need evidence and valid criteria. |
| Acquisition lock | Binding received with work for a submission protocol; not a financial or production permission. |
| Queue acknowledgment | Local bookkeeping that an item was handled; not necessarily successful remote acceptance. |
| Cancellation | Request to stop work; not proof of rollback, thread termination or remote shutdown. |
| Search budget | Count/time/resource limit; different from verified subscription entitlement or cash cap. |

See [comparison and consumer mapping](self-improvement-comparison.md) for how to
reuse these distinctions without importing an entire upstream system.
